# Legislation label for Section 60 searches

The exact string that data.police.uk uses in the `Legislation` column of
stop-and-search files for searches under section 60 of the Criminal
Justice and Public Order Act 1994 (verified 2026-09-16).

## Usage

``` r
lamp_s60_legislation()
```

## Value

A string.
